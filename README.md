# Java Caesar Cipher

A Java implementation of the Caesar Cipher encryption algorithm. This program allows users to encrypt messages by shifting letters in the alphabet by a user-defined amount while preserving letter case and leaving non-alphabetic characters unchanged.

## Features

- User input using `Scanner`
- Custom shift value for encryption
- Supports uppercase and lowercase letters
- Preserves spaces, numbers, and symbols
- Uses `StringBuilder` for efficient string manipulation

## Example

Input:

```text
Enter a message: Hello World
Enter a shift value: 3
```

Output:

```text
Encrypted message: Khoor Zruog
```

## Technologies Used

- Java
- Scanner
- StringBuilder
- Loops
- Conditional Statements

## How to Run

Compile the program:

```bash
javac Main.java
```

Run the program:

```bash
java Main
```
